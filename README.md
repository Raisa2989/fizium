# ФизиУм — учебник-тренажёр по физике для 7–11 классов

Полноценное PWA-приложение: полный школьный курс физики с теорией, интерактивным
тренажёром, справочник физических постоянных и шпаргалкой формул. Устанавливается
на телефон или компьютер как приложение и работает **офлайн**.

**Приложение полностью статическое: сервера, API и базы данных нет.**
После сборки это просто набор файлов (HTML/CSS/JS), который размещается
на любом статическом хостинге. Прогресс занятий хранится на устройстве.

## Возможности

- **2 этапа**: 7–9 классы (подготовка к ОГЭ) и 10–11 классы (подготовка к ЕГЭ)
- **2 уровня** в каждом этапе: базовый и углублённый (углублённый = база + 130 задач повышенной сложности и блоки «Углубление» в теории)
- **82 темы**, **872 вопроса** с подробным разбором каждого ответа
- **4 типа заданий**: выбор ответа, множественный выбор, ввод ответа, соответствие
- **Шпаргалка формул**: все формулы курса по классам и разделам, с расшифровкой величин и поиском
- **Справочник**: физические постоянные, единицы СИ, приставки, греческий алфавит, плотности, переводы единиц
- **Прогресс и достижения** — хранятся локально на устройстве
- **PWA**: манифест, service worker, офлайн-режим, установка на телефон/десктоп

Содержание соответствует федеральным рабочим программам по физике
(базовый и углублённый уровни, ФГОС ООО/СОО, 2025 г.).

## Публикация

### Шаг 1. GitHub — бесплатно, с автоматической сборкой

1. Создайте аккаунт на [github.com](https://github.com) (если ещё нет).
2. Создайте репозиторий: кнопка **New** → имя (например, `fizium`) → **Create repository**.
3. Загрузите код из этого архива в репозиторий:

   **Вариант А — через программу [GitHub Desktop](https://desktop.github.com) (без команд):**
   распакуйте архив на компьютер → в GitHub Desktop: **File → Add repository → Create a New Repository** →
   выберите папку с распакованным проектом → **Create** → **Publish repository**.

   **Вариант Б — через терминал (5 команд):**
   ```bash
   cd путь/к/распакованной/папке
   git init
   git add .
   git commit -m "ФизиУм"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/fizium.git
   git push -u origin main
   ```

4. Включите Pages: **Settings → Pages → Source: GitHub Actions**.
5. Откройте вкладку **Actions** — сборка запустится автоматически.
   Через 2–3 минуты сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/fizium/`.

### Шаг 2. reg.ru или другой хостинг (свой домен)

1. В репозитории на GitHub откройте вкладку **Actions** → последний успешный запуск →
   внизу раздел **Artifacts** → скачайте **fizium-static-site** (готовый сайт, сборка для корня домена).
2. Распакуйте архив и загрузите его содержимое в папку `public_html` вашего хостинга
   (в reg.ru — через файловый менеджер или FTP).
3. Включите HTTPS-сертификат (Let's Encrypt — бесплатно, в панели хостинга).

Тариф нужен самый простой: **без Node.js и баз данных** — только статический хостинг.

## Локальный запуск (для доработки)

Нужен [Bun](https://bun.sh) (или замените на npm/node — команды аналогичны):

```bash
bun install        # установить зависимости
bun run dev        # запуск: http://localhost:3000
bun run build      # статическая сборка в папку out/
```

Открывать `out/index.html` напрямую не нужно — используйте dev-сервер или хостинг.

## Технологии

- **Next.js 16** (App Router, статический экспорт) + **TypeScript**
- **Tailwind CSS 4** + shadcn/ui, **Framer Motion** для анимаций
- **Zustand** для состояния (прогресс в localStorage)
- Палитра **«Вишня и шоколад»**: вишнёвая гамма для 7–9 классов (ОГЭ),
  шоколадная — для 10–11 (ЕГЭ); классы окрашены от светлой вишни (7 класс)
  к горькому шоколаду (11 класс); углублённый уровень — тёмный шоколад.

## Структура проекта

```
src/
  app/            — корневые layout и страница
  components/     — интерфейс: shell, виды (главная, этап, тема, тренажёр, справочник, формулы)
  data/           — контент: grade7…grade11 (теория и вопросы), справочник, формулы
  lib/            — store (Zustand), темы этапов, разметка формул
public/           — манифест PWA, иконки, service worker
scripts/          — подсчёт статистики контента
```
